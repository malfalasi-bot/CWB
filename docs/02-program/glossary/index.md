# Glossary — the program's compendium

2026-09-28 · @Mohammad AlFalasi

## How the glossary works

Every term the program uses on purpose is here once, in plain words, with the unit where a learner first meets it, the terms it connects to, and — for the briefer lane — one line on how to use it with a designer; version 1 holds the program's core vocabulary and F1's, about ninety terms, and grows with each module through the factory.

**Rules for entries**

1. A term enters the glossary when a unit introduces it; it is never used in unit copy before its unit.
2. One term per idea; synonyms are listed as "also called", never used interchangeably.
3. Meanings are one or two sentences, written for someone who has not studied design.
4. "Met in" is the first unit; later uses are found through the Atlas and the unit register, not listed here.
5. "Say it to a designer" appears where a briefer would use the idea in a meeting or a brief.
6. In the app, every term is a link wherever it appears; "Related" terms are links too, which is what makes this a compendium rather than a list.
