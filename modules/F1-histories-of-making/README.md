# F1 Histories of making

The first Foundations module. It teaches a global history of making as a web of objects, makers, places, routes and institutions. Its threshold concept is that design history is a web with obscured strands, not a line. F1 has 35 units at structure v3.6. Gate G1 passed on 28 September 2026. Phase 4 is under way, and spec batch 1 (eight units) was written on 29 September 2026.

## What is here

| Folder | Contents |
|---|---|
| `docs/` | The module's documents, in order, as Markdown and PDF (listed below) |
| `specs/` | Unit specs on template v3, one Markdown file per unit; these are the authoring sources for the batch-1 doc |
| `grouping-pages/` | Five grouping pages from round 2: the Indian Ocean, the Indus Valley civilisation, the waqf, Arts and Crafts, the Middle Horizon. The first three (Mingei, Nok, Igun Eronmwon) are inside the Groundwork document |
| `atlas/` | The Atlas data and its jobs: the canon register (4,228 nodes), the world-set, claims and practices registers, 198 zero-cost source routes, 130 primary texts, the harvesters, validation, coverage and the licence switch. See `atlas/README.md` |
| `briefs/` | The briefs research agents worked to: canon schema and codes, grouping pages, unit specs |
| `research/` | Studies behind decisions: licensing routes, object-type density, how civilisations and movements are treated, the round-2 blind map, the AP-250 coverage check, licence verification notes |
| `review-logs/` | Fact-check logs for the canon, including the lint fixes of 29 September |
| `design/mockups/project/` | The mockups (version 4): nine artboards and the canvas file. They need the Design runtime to render, so open them from the live mockups link below |
| `exports/` | The canon register as a workbook, for reading without code |
| `build/` | The scripts that built the canon and registers, kept as a record of method. They ran once in a scratch workspace, and their input and output paths point there |
